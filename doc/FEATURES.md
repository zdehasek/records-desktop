# Features

## Photos And Videos

- Photo and video daily timeline
- Week and year overviews
- Media browsing, filtering, and search
- Centered On This Day view for monthly and yearly memories
- Curated memory story playback and privacy-safe daily reminders
- Captions, sticky-note colors, and important markers

## Media

- Photo and video import into `records/` in a starred media folder
- Photos, videos, and map views
- Lightbox metadata editing
- Duplicate and missing-file management
- HTTP byte-range video streaming
- Cached MP4 remux/transcoding for browser-incompatible video or embedded-audio
  codecs
- EXIF-aware imports and generated image/video thumbnails
- Recursive in-place folder indexing with periodic incremental scans
- File-authoritative captions, important state, visibility, dates, and GPS
- Optional Markdown companions for editable video captions and metadata
- Random important-media covers for day, range, and memory views
- Ordered standalone photo-to-GIF creation
- Offline map tile caching around recorded locations

## Organization

- Visibility folders and hidden records
- Batch visibility and deletion actions
- NSFW hiding or blurring
- Move-only system Trash deletion
- Named media roots with a starred default Add destination

## Omarchy

- Bar widget with a live On This Day preview and story action
- `Alt+5` in-app navigation and optional `Super+Shift+R` desktop shortcut
- Clickable native On This Day notifications at a configurable local time
- One backend shared across monitor-specific bar instances
- Isolated Chromium profile
- Backend crash restart and visible Chromium launch errors
- No Electron, mobile wrapper, cloud account, subscription, calendar sync, or
  application-level updater
